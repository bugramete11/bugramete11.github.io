# 🚀 Kişisel Portfolyo Web Sitesi | Buğra Mete Tura

Merhaba! Ben **Buğra Mete Tura**. Bilecik Şeyh Edebali Üniversitesi'nde Web Tasarım ve Kodlama öğrencisiyim. Bu depo (repository), kişisel portfolyo web sitemin kaynak kodlarını içermektedir.

Sitem, yazılım dünyasındaki serüvenimi, öğrendiğim yeni teknolojileri ve üzerinde çalıştığım algoritmaları sergilediğim dijital vitrinimdir.

> ⚠️ **Geliştirme Süreci:** *Bu web sitesi statik bir proje değildir; **sürekli olarak geliştirilmeye devam etmektedir.** Yeni teknolojiler öğrendikçe tasarımsal güncellemeler yapıyor, backend mimarileri kuruyor ve yeni geliştirdiğim projeleri buraya entegre ediyorum.*

## 🛠️ Kullanılan Teknolojiler

Sitenin geliştirilmesinde ve sergilenen projelerin altyapısında aşağıdaki teknolojiler kullanılmıştır:

* **Frontend:** HTML5, CSS3, JavaScript
* **Tasarım & UI/UX:** Figma
* **Yazılım & Veritabanı (Projeler):** C#, MSSQL

## 📂 Öne Çıkan Projelerim

Şu an sitemde sergilenen ve kaynak kodlarına erişilebilen aktif projelerim:

1. **Farklı Rengi Bulma Oyunu:** JavaScript ile geliştirilmiş, DOM manipülasyonu içeren eğlenceli ve interaktif bir tarayıcı oyunu.
2. **Otopark Takip Sistemi:** C# ve MSSQL veritabanı entegrasyonu ile araç giriş-çıkış süreçlerini yöneten sistem altyapısı.
3. **Dinamik Fibonacci Dizisi:** Kullanıcının girdiği dinamik sayı adetine göre kusursuz çalışan C# Fibonacci algoritması.
4. **Asal Sayı Bulma Uygulaması:** Kullanıcının belirlediği 1 ile 100 aralığındaki asal sayıları tespit edip yan yana ve düzenli şekilde listeleyen C# uygulaması.
5. **Gelişmiş Hesap Makinesi:** Klasik işlemlerin ötesinde üçgen ve daire alanı hesaplayabilen, kök alma işlemleri yapabilen gelişmiş C# hesap makinesi.

## ✨ Sitedeki Özel Yapılar

* **Cam Efektli (Glassmorphism) Modern Tasarım:** Koyu tema ağırlıklı, neon renk vurgularına sahip profesyonel arayüz.
* **Akıllı Ziyaretçi Paneli (Visitor Info):** Üçüncü parti API'ler ve `localStorage` kullanılarak ziyaretçinin IP adresi, konumu, tarayıcısı, işletim sistemi, ekran çözünürlüğü ve site ziyaret sayısını dinamik olarak ekrana yazdıran özel JavaScript paneli.
* **Modüler Grid Sistemi:** Tüm yeteneklerin, projelerin ve iletişim kanallarının esnek ızgara (CSS Grid/Flexbox) yapısıyla responsive (mobil uyumlu) şekilde sergilenmesi.
